# Restaurant Asset Manager Pro

Professional desktop software for restaurant app developers.

## Features

- Project Management
- Image Manager
- Categories
- Menu Management
- Cloudinary Integration
- Firebase Integration
- Flutter Export
- AI Image Matching
- WebP Converter

## Tech Stack

- Firebase
- Git
- GitHub
